🔓 Skip Humplex Sign-in

This is a way for those who want to bypass the Blogger sign-in page on Humplex.

WHAT YOU'LL NEED:

  • Violentmonkey userscript manager
  • Blogspot Warning Bypass script from Greasy Fork

INSTRUCTIONS:

  1. Install Violentmonkey.
  2. Go to the Blogspot Warning Bypass script page.
  3. Click the "Install this script" button.
  4. Click the "Install" button in the window pop-up.

Now surf Humplex without the Blogger sign-in page! 😃

BONUS TIP:

You can also use userscripts on mobile.

  • Android: Firefox Violentmonkey add-on
  • iOS: Safari Userscripts app.
